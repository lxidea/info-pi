# Info-Pi · 1920×440 外壳设计

参数化 3D 打印外壳，承载 BOE QV101F6M-N10 屏幕 + HM-V1.0B 驱动板 + Orange Pi Zero 2W。

## 文件说明

- `enclosure.scad` — 参数化主模型（OpenSCAD）
- 输出 STL（需要 OpenSCAD 渲染）：
  - 前框 (`front`)
  - 后盖 (`back`)
  - 壁挂底板 (`wall`)

## 设计概览

整体是一块薄板，约 **273 × 73 × 17mm**（减薄设计：缩短螺柱高度 + 取消多余空气间隙）：

## 装配方式

1. **前框** 内陷盛放屏幕（屏幕粘贴或夹紧固定）
2. **后腔** 内壁伸出**矮柱**（高度 = `board_back_gap` = 2mm），驱动板（M3）和 Pi（M2.5）用螺丝固定。两块板都**贴着后盖**装，元件面朝屏幕——这样接口和 SoC 蒸发器的高度全部让给前面（屏幕侧），蒸发器不会顶到屏幕。螺丝穿过矮柱**钻进后盖壁**取得足够旋入深度（盲孔，距外表面 0.5mm）。
3. **后盖** 通过 4 颗 M3 螺丝（沿边缘）合上整体
4. **VESA 接口** 后盖中央有 4 个 M3 黄铜热熔螺母，壁挂底板拧上
5. **走线**：
   - **底部中间** 36×9mm 开口 — Type-C 电源线从这里进入外壳
   - **底部 Pi 端** 13×2.5mm 扁口 — microSD 卡从这里凸出 ~1mm 便于抓取
     - 不拆机也能换 SD 卡（升级系统、备份等）
   - **底部 驱动板端** 8×1.5mm 扁口 — 预留触摸面板 FFC 排线（可选，默认开启）
     - 注意：驱动板 180° 旋转后 I2C 接口在底长边，所以触摸 FFC 槽从顶壁移到底壁

### 内部 HDMI 走线（Pi → 驱动板）

**视角约定**：
- "**正面视角**"：穿过屏幕看，看到屏幕背后的两块板。驱动板在**左**、Pi 在**右**
- "**背面视角**"（OpenSCAD 默认视角）：直接看屏幕背面。驱动板在**右**、Pi 在**左**
- 上下不变，只有左右镜像翻转

**关键设计点**：
- Pi 的 HDMI/USB 在右长边，**朝向腔体中心**（朝向驱动板方向）
- 驱动板**整体 180° 旋转**：HDMI/USB-C 在右短边，**朝向外侧右壁**；FPC 排线接口在左短边，朝向腔体中心；I2C 触摸接口在底长边
- 两块板的 HDMI 口**朝同一方向**（都朝右），所以需要 **90° 弯头 Mini-HDMI 线**
- 驱动板右侧预留 **22mm 间隙**容纳 HDMI 弯头插头体

```
后视图（看进腔体内部）：

┌────────────────────────────────────────────────────────────────────┐
│                                                                    │
│  ┌─────┐                                                          │
│  │     │ ← USB-C 电源                                              │

│  │  ×  │ ← Mini-HDMI ──────────────────────┐                     │
│  │ 65  │                                    │                     │
│  │     │     ┌──── Driver 72×49 ────┐      │                     │
│  │     │     │                  USB-C│   ←─ 在外侧     ║║ 22mm 间隙│
│  │     │ FPC←│                       │HDMI←┘ 90°弯头  ║║         │
```

**布局要点**：

| 部件 | 朝向 | 备注 |
|------|------|------|
| Pi | **竖放**（90° 顺时针旋转），30mm 宽 × 65mm 高 | 右长边面向驱动板 |
| Pi 接口（右长边） | 从上到下：USB-C → USB-C → Mini-HDMI | 都朝右（朝向驱动板）|
| Pi SD 卡 | 从底短边向下凸出 4mm | 穿过底壁 13×2.5mm 扁口（外部换卡） |
| Pi 辅助 FFC（顶短边）| 摄像头排线接口（可选） | 顶部预留 |
| 驱动板 | **横放**，PCB 整体在板平面内旋转 180° | HDMI/USB 朝外（右壁），FPC 朝内（朝 Pi）|
| 驱动板右短边 | **上 USB-C，下 Mini-HDMI**（180° 旋转后）| **朝向外侧右壁**，留 22mm 间隙给 HDMI 弯头插头 |
| 驱动板左短边 | FPC 排线接口 | 朝向腔体中心，需用回折/绕行的 FPC 线 |
| FPC 排线 | 从屏幕短边引出，回折到驱动板左短边 | 需要足够长的 FPC（约 10-15cm 排线长度）|
| 触摸 FFC | 从驱动板**底长边** I2C 出 | 通过**底壁**扁口出腔体（不是顶壁）|

**HDMI 线推荐**：

- 由于两端 HDMI 都朝右，需要至少**驱动板一端 90° 弯头**
- 长度选 **20-30cm**（够弯头到 Pi 的环绕路径 + 弯曲冗余）
- 淘宝搜词：**"miniHDMI 公对公 90度弯头 20cm"** 或 **"L 形 mini-HDMI 短线"**
- 弯头方向：朝下 / 朝上均可（取决于实际走线，建议买可旋转的）

**FPC 走线注意**：

- 屏幕 FPC 排线从屏幕短边引出，原本预期"贴到驱动板右短边"
- 驱动板 180° 旋转后，FPC 接口在驱动板的**左短边**（朝向 Pi 方向）
- 排线需要**回折**：从屏幕短边出来后，绕到屏幕背面、向 Pi 方向延伸到驱动板左短边
- 装配时确认 FPC 排线**长度够用**（建议先用临时方式上电点亮，再固定外壳）

**电源方案**：

- 单一 Type-C 5V/2A 从底部进入
- 内部用 Type-C 一分二分线给 Pi 和驱动板各供一路

## 壁挂方案

后盖中央有 75×35mm VESA 风格的螺孔阵列（4 个 M3），通过四颗螺丝固定到壁挂底板。

**壁挂底板**特性：
- 顶部**钥匙孔槽**——只需在墙上拧一颗螺丝，把底板挂上去
- 底部**防转销孔**——附加第二颗螺丝防止外壳转动
- 4 颗 M3 沉头螺丝把后盖固定到底板上
- 拆装方便：维护时直接抬起底板从挂钩取下

**散热组件** 是 DIY 套件（无 CNC / 无焊接），由**三个独立零件**组成——① 吸热盘 hold-down 压板（无翅片，压在热管上方）② 弯折热管 ③ 放热段翅片散热器（finned condenser）。

吸热端的层叠顺序是 **芯片 → 热管扁平端 → 吸热盘压板**：Ø6 热管压扁后仍约 6mm 宽（不是一块方板），其扁平端直接贴在 SoC 上；吸热盘是一个带凹槽的小压板（bracket），凹槽卡住这段 6mm 热管、两侧的肩脚落到 PCB 上，用螺丝把热管压紧到芯片上（热管夹在压板和芯片中间）。压板顶只到 z≈10.9，屏背在 z≈11，深度基本占满。热管的放热端用导热胶粘进散热器底部凹槽。

因此不是三视图，而是**弯管 / 走线图**：

| 文件 | 用途 |
|------|------|
| `heat_pipe_cooler_DIM.pdf` / `.svg` | 弯管模板：各段长度、4 处弯折（B1/B3/B4 = 90°，B2 = Z 向台阶）、吸热端层叠剖面（芯片→热管→压板）、Z-drop 深度剖面（6.9→2.5）、放热段挤型剖面（30×18×8，15 片鳍 @2mm 间距，6×3 凹槽）、展开长度 ~128mm + 下料长度 |
| `hold_down_clamp.stl` · `heat_pipe.stl` · `condenser.stl` | **三个零件分开**的 3D 参考（无标签；非打印件）|
| `heat_pipe_cooler.stl` | 三者合并的装配参考 |

> 翅片高度受机身厚度限制：整机仅 17mm 深，风扇/翅片顶已到 z≈10，屏背在 z≈11，因此翅片高 6.5mm 已接近上限；**密度**（9→15 片）是散热提升的主要手段。

## 打印建议

- **前框 + 壁挂底板**: PETG（推荐，耐热 80°C）或 PLA（70°C 上限）
- **后盖**: PLA/PETG 即可（**不再要求金属**）
  - SoC 朝屏幕、够不到后盖，所以后盖不再是主散热体，只承担风扇进风格栅 + 鲍片风道
  - 想额外加分可印铝板，给驱动板/背光的辐射散热加一点面积，但对 H618 无直接帮助（H618 走热管）
  - 长时间运行时建议**监控 CPU 温度**（dashboard 自带）
- **层高**: 0.2mm
- **填充**: 20%
- **壁厚**: 文件中 `front_wall=2 / side_wall=2 / back_wall=2`
- **支撑**: 后盖的安装柱不需要支撑（自下而上打）；前框可能需要少量支撑

## 散热设计

> **重要前提**：Pi 的**元件面（H618 SoC + 全部接口）朝屏幕**，不朝后盖。所以
> SoC **无法**像早期设计那样把散热块直接顶到后盖——「SoC→散热块→后盖」这条
> 被动传导路径已经不存在。H618 的热量改由**热管**搬到中段冷凝，背盖不再是主散热体。

两条可用路径：

1. **对流路径（始终有效）**：
   - 前框顶壁 10 条 15×1.5mm 通风缝（热气排出）
   - 前框底壁 ~8 条通风缝（穿插在 SD/电源/触摸 FFC 切口之间，冷气进入）
   - 烟囱效应驱动腔内气流，带走屏幕 LED 背光 + 驱动板电源芯片的热
   - H618 仅 1–3W，单靠对流缝在常态负载下通常也够；下面的热管是冗余/保险

2. **热管主动路径（H618 专用，见下节）**：
   - 蒸发器贴在朝屏幕一面的 SoC 上，热管把热水平搬到腔体正中的鲍片+风扇散掉
   - 这是 SoC 唯一的「定向」散热通道（因为它够不到后盖了）

后盖可以用塑料：它只承担风扇进风格栅 + 鲍片风道，不再需要金属导热。

### 主动散热：热管 + 远端涡轮风扇（DIY 套件，免 CNC / 免焊）

H618 SoC **紧邻 Mini-HDMI**（据官方板图，native≈(40,15) → placed(15,25)，在 HDMI 带内）、在**朝屏幕**那一面，够不到后盖。解法借鉴笔记本：用一根**成品压扁热管**把 SoC 的热水平搬到腔体**正中**那块空地（两根 VESA 螺柱之间），在那儿用涡轮风扇 + **现成铝散热器**散掉。冷却硬件整体远离接口和挂架螺柱，排线随便走。

> **全部现成件 + 导热环氧，无需机加工/钎焊**：成品压扁热管（按长度买）的扁端**直接压 SoC 裸 die**——热管本身就是冷板，省掉订制蒸发块；另一端用导热环氧**粘进现成挤压铝散热器**底座的开槽里，省掉钎焊鳍片。真正的「订制」只剩下按实物把热管**弯折成形**这一步。

```
 SoC(朝屏幕面, 紧邻HDMI, 全局y≈28)
   │ 先竖直跳到 y≈36 车道（SoC 在 HDMI 带内，必须先让开）
   │ 再沿腔体中线横走 y≈36（穿过 HDMI[y20-31] 与 OTG[y41-50] 之间，
   │                         也在两排 VESA 孔 y19/y54 之间）
   └─出Pi后下沉到背盖平面─→ 风扇左侧(x≈115)爬升 ─→ 冷凝散热器(x≈135)
                                                      ↑ 风扇吹(+y)
                                          背盖格栅吸风→涡轮→穿鳍片→顶壁vent
```

- **热管**：成品 Ø6 圆管压扁成 `6×3mm`（`hp_w`/`hp_t`，也可直接买预压扁款），塞进薄腔。屏幕壁挂横置 → 热管**水平放置**，蒸发端和冷凝端等高，无重力惩罚（热管最忌蒸发端朝上）。扁端隔一层导热垫**直接压朝屏幕一面的 SoC die**（不另做蒸发块），另一端导热环氧粘进散热器开槽。
- **走线（关键）**：SoC 紧邻 HDMI（全局 y≈28，落在 HDMI 带 y20-31 内），所以热管**先在 x≈27（接口左侧、不碰任何接口）竖直跳到 y≈36**，再沿 **腔体中线 y≈36** 横走——这条车道一举三得：① 在 Mini-HDMI（y20-31）和 USB-C OTG（y41-50）两个接口**之间**穿过；② 在上下两排 VESA 螺孔（y19 / y54）**之间**穿过；③ 出了 Pi 右缘（x>50，已无 PCB）就**下沉**到背盖平面，到风扇左侧（x≈115）爬升、拐入散热器。全程经过 VESA 柱旁留 10-11mm 余量，`cooler_mounts()` 在中线车道印两道压管卡槽（x65/x100）固定。
- **冷凝散热器**：`fin_cx=135` 处一块 30mm 宽的**现成挤压铝散热器**（模型按 9 片鳍 `n_fins` 示意），底座铣一道槽埋热管，立在风扇喷口正上方，气流沿 y 方向穿过 → 顶壁 vent。买现成、免做鳍。
- **涡轮风扇**：3007（`fan_t=7`，风量大）或 3004（`fan_t=4`，更薄静音），位于鲍片**正下方**的腔体正中（`fan_cx=135, fan_cy=24`）——`fan_cx=135` 正好落在两根 VESA 螺柱（x=99 / x=174）正中间的空地，不再与挂架孔位打架。背盖同心环格栅吸新风 → 切向喷口朝上（+y）→ 穿过鲍片 → 顶壁 vent 排出。
- **安装**：背盖 4 角定位肋 + 2 对角 M2 螺柱（`fan_cradle()`），散热器基座两道定位墙（`cooler_mounts()`）。

**接口/排线/挂架彻底解放**：冷却硬件全在腔体正中空地，既不挡 Pi 右缘的 Mini-HDMI / 两个 USB-C（排线最短路径走），也不压 VESA 挂架螺柱。这是热管相对「风扇贴 SoC」方案的核心优势。

**Pi 调速控制（2 线风扇 + N-MOS 低端开关）：**

```
              +5V ──────────────┬──────────────┐
                                │            (风扇 +)
                              [风扇]          1N4148
                                │          (续流二极管)
              (风扇 −) ─────────┴──────────────┘
                                │
                          ┌─────┴─────┐ Drain
   Pi GPIO18 ──[100Ω]──── G  AO3400   │   (N沟道 MOSFET)
        (PWM) │           └─────┬─────┘ Source
              │                 │
            [10kΩ]              │
              │                 │
             GND ───────────────┴────────── GND（与 Pi 共地）
```

- **GPIO18**（硬件 PWM 引脚）经 100Ω 限流接 MOSFET 栅极，10kΩ 下拉保证开机/浮空时风扇默认关断。
- **AO3400 / 2N7000** N 沟道 MOSFET 低端开关：栅极 0–3.3V 即可控制 5V 风扇，无需电平转换。
- **1N4148 续流二极管**跨接风扇两端（负极接阳极），泄放 PWM 关断时的线圈反电动势，保护 MOSFET。
- 风扇 +5V 取自 Pi 排针或 USB-C 供电的 5V，**务必与 Pi 共地**。

**软件（按 CPU 温度调速，`gpiozero`）：**

```python
from gpiozero import PWMOutputDevice
from time import sleep

fan = PWMOutputDevice(18, frequency=25000)  # 25kHz，避开可闻噪声

def cpu_temp():
    with open("/sys/class/thermal/thermal_zone0/temp") as f:
        return int(f.read()) / 1000

while True:
    t = cpu_temp()
    if   t < 45: fan.value = 0.0     # 停转
    elif t < 55: fan.value = 0.4     # 低速
    elif t < 65: fan.value = 0.7     # 中速
    else:        fan.value = 1.0     # 全速
    sleep(5)
```

> 提示：25kHz PWM 频率在人耳听觉范围之外，避免风扇低频啸叫。停转阈值留 ~45°C 让常态静音，靠传导散热即可。
