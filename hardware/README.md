# Info-Pi · 1920×440 外壳设计

参数化 3D 打印外壳，承载 BOE QV101F6M-N10 屏幕 + HM-V1.0B 驱动板 + Orange Pi Zero 2W。

## 文件说明

- `enclosure.scad` — 参数化主模型（OpenSCAD）
- 输出 STL（需要 OpenSCAD 渲染）：
  - 前框 (`front`)
  - 后盖 (`back`)
  - 壁挂底板 (`wall`)

## 设计概览

整体是一块薄板，约 **280 × 80 × 15mm**：

```
正视图（屏幕朝外）：
┌──────────────────────────────────────────────────┐
│                                                  │  ← 前框 2mm
│      ┌────────────────────────────────────┐      │
│      │                                    │      │  显示窗口
│      │      显示区 261 × 61 mm            │      │  (内陷 2mm 遮挡屏幕边缘)
│      │                                    │      │
│      └────────────────────────────────────┘      │
│                                                  │
└──────────────────────────────────────────────────┘
     ← 总宽 281mm →

后视图（看后盖）：
┌──────────────────────────────────────────────────┐
│   ┌──────────┐                  ┌──────────┐     │
│   │ Orange Pi│                  │  驱动板  │     │
│   │ 65×30    │                  │  72×50   │     │
│   └──────────┘                  └──────────┘     │
│                                                  │
│           ▣ ▣                                    │  ← VESA 75×35 安装孔
│           ▣ ▣        ┌──┐                       │  ← 线缆出口
│                       └──┘                       │
└──────────────────────────────────────────────────┘

侧视图（厚度 ~15mm）：
┌────────────────┐
│ 前框 + 屏幕     │ 4+2 = 6mm
├────────────────┤
│ 后腔（驱动板/Pi）│ 7mm 
├────────────────┤
│ 后盖            │ 2mm
└────────────────┘
```

## 关键参数（在 enclosure.scad 顶部修改）

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `screen_w / h / t` | 265 / 65 / 4 | 屏幕外形 |
| `board_w / h / t` | 72 / 50 / 4 | 驱动板含元器件 |
| `pi_w / h / t` | 65 / 30 / 7 | Orange Pi（含 USB-C 高度）|
| `bezel_inset` | 2 | 前框遮挡屏幕边的宽度 |
| `back_clearance` | 3 | 屏幕与后腔元器件的空气间隙 |
| `mount_spacing_x / y` | 75 / 35 | VESA 螺孔间距 |
| `board_hole_d / inset` | 2.5 / 3 | 驱动板螺丝孔径 + 距角偏移 |

## 装配方式

1. **前框** 内陷盛放屏幕（屏幕粘贴或夹紧固定）
2. **后腔** 内壁伸出柱子，驱动板和 Pi 用 M2.5 螺丝固定
3. **后盖** 通过 4 颗 M3 螺丝（沿边缘）合上整体
4. **VESA 接口** 后盖中央有 4 个 M3 黄铜热熔螺母，桌脚/壁挂底板二选一装上

## 壁挂方案

后盖中央有 75×35mm VESA 风格的螺孔阵列（4 个 M3），通过四颗螺丝固定到壁挂底板。

**壁挂底板**特性：
- 顶部**钥匙孔槽**——只需在墙上拧一颗螺丝，把底板挂上去
- 底部**防转销孔**——附加第二颗螺丝防止外壳转动
- 4 颗 M3 沉头螺丝把后盖固定到底板上
- 拆装方便：维护时直接抬起底板从挂钩取下

## 渲染和导出

```bash
# 安装 OpenSCAD（如未安装）
sudo apt install openscad

# 命令行渲染单个部件为 STL
openscad -D 'part="front"' -o front.stl enclosure.scad
openscad -D 'part="back"' -o back.stl enclosure.scad
openscad -D 'part="wall"' -o wall.stl enclosure.scad

# 或者在 OpenSCAD GUI 里打开 enclosure.scad
# 修改 part 变量，按 F6 渲染，File→Export→STL
```

## 打印建议

- **材料**: PETG（推荐，耐热 80°C）或 PLA（70°C 上限）
- **层高**: 0.2mm
- **填充**: 20%
- **壁厚**: 文件中 `front_wall=2 / side_wall=2 / back_wall=2`
- **支撑**: 后盖的安装柱不需要支撑（自下而上打）；前框可能需要少量支撑

## 螺丝清单

| 用途 | 规格 | 数量 |
|------|------|------|
| 驱动板固定 | M2.5×6 自攻 | 4 |
| Orange Pi 固定 | M2.5×6 自攻 | 4 |
| 后盖合体 | M3×12 沉头 | 4-6（沿边） |
| VESA 热熔螺母 | M3 黄铜嵌件 | 4 |
| 挂架/桌脚连接 | M3×8 沉头 | 4 |

## 待办（量产前需验证的尺寸）

- [ ] 驱动板螺丝孔的**实际孔径和孔距**（当前假设 M2.5、3mm 内陷）
- [ ] 屏幕背面是否完全平整（影响 `back_clearance`）
- [ ] Orange Pi 走线方向（HDMI/USB-C 的入口需要侧面预留空间）
- [ ] 触摸屏 6-pin I2C 接口（暂时不用，但布线位置可预留）

## 工作流程

1. 先用默认值 3D 打印**一个驱动板托盘**（只渲染后盖局部）验证孔位
2. 通过后再打印完整外壳
3. 装配前用游标卡尺再测一遍最终件
